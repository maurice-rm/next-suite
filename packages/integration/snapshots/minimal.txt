+# my-app
+
+A [Next.js](https://nextjs.org) app created with
+[create-next-suite](https://github.com/maurice-rm/next-suite).
+
+## Getting started
+
+```bash
+pnpm run dev
+```
+
+Open [http://localhost:3000](http://localhost:3000) in your browser.
+
+## Scripts
+
+| Script | Command |
+| --- | --- |
+| `dev` | `next dev` |
+| `build` | `next build` |
+| `start` | `next start` |
+| `typecheck` | `next typegen && tsc --noEmit` |
+
+## Security headers
+
+`security-headers.ts` sets a static Content Security Policy and the common security headers for every route. HSTS leaves out `includeSubDomains`, so subdomains keep plain HTTP until you opt in.
