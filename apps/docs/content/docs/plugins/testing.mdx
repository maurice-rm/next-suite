---
title: Testing plugins
description: Test the projects create-next-suite generates.
---

`create-next-suite/testing` generates a project and runs its scripts, the way the CI of
create-next-suite checks its own plugins with every package manager:

```ts title="project.test.ts"
import { createTestProject } from 'create-next-suite/testing'
import { expect, test } from 'vitest'

test('the project builds with Biome', async () => {
  const project = await createTestProject({
    plugins: [],
    answers: { linter: 'biome' },
    install: true,
  })

  expect((await project.run('build')).isSuccess).toBe(true)
})
```

Every question you leave out takes its default; git stays off. Run the checks of the generated
project, such as `typecheck`, `lint` and `test`.

## In this version

Plugins from outside create-next-suite cannot be loaded yet, so a test project holds built-in
plugins only: an address in `plugins` makes `createTestProject` fail, and
`next-suite plugin validate` stops with a message. Both return for plugins written as `plugin.ts`,
together with the helpers to test a plugin of your own.
