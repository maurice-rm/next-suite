# Contributing

Thanks for helping with next-suite. [README.md](README.md) shows how to set up the repository and
which commands it has; [AGENTS.md](AGENTS.md) sums up how code is written here, for people and
agents alike.

- **Issues:** open one for a bug, a feature or a question. A new built-in plugin, a change to the
  plugin contract, the CLI's commands or flags, or the vocabulary starts as an issue, before any
  code.
- **Plugins of your own** need no change here: a plugin can live in its own repository, public or
  private.
- **Pull requests:** against `main`, one concern each, with the checks from AGENTS.md passing.
  A change to what `create-next-suite` ships or generates has a changeset (`pnpm changeset`).
- **Vulnerabilities:** report them privately, as [SECURITY.md](SECURITY.md) describes.

Everyone taking part follows the [Code of Conduct](CODE_OF_CONDUCT.md).
